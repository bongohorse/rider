# Ideas

A library of **unscheduled ideas** and **historical issue planning references**. Some referenced issues are already in progress or completed, but documents here are never implementation authorization.

**Rules for agents**

- Do not implement anything solely from this folder. Live GitHub issues, owners, explicit GO, dependencies and active contracts control implementation.
- Do not read this folder for routine tasks. A historical brief does not override current work order, issue status, owner or acceptance.
- You may add notes to an idea (technical approach, risks, cost) when asked, or link it from an issue that touches the same area.

**How to use it**

- One file or thematic subdirectory per large idea; smaller unscheduled concepts stay in [roadmap.md](roadmap.md).
- Status at the top of each file: `raw` (just written down) · `worked out` (approach, risks, cost sketched) · `ready` (could become issues) · `scheduled` (issue/milestone exists, link it) · `dropped` (keep the reason).
- Keep it short: goal, why it is fun, rough approach, risks, open questions, smallest playable version.
