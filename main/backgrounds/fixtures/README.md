# Background renderer test images

Original deterministic RGBA diagnostics generated by `tools/backgrounds/fixtures.py`, without external assets or randomness. `grid.png` is a 64×32 coordinate gradient; `foreground.png` is a translucent solid used to prove clipping. The adjacent 1×1 `seed.png` is only the mesh prototype's empty texture slot. These are Gym fixtures, not environment preset art; #547 owns that art and its provenance. The raw diagnostics are bundled as custom resources so the same PNG decode/texture ownership route runs in the pinned engine.
