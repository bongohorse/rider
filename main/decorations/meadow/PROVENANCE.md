# Meadow decorations

Every pixel is generated by `tools/art/decorations.py` with Pillow. Inputs are that file and its fixed seed 5670. No archive, external image, reference still or third-party asset is an input. `--write` reproduces the set; `--check` verifies committed files without any source archive. Kenney test assets are not part of this set. Claudio approves art direction in #560.
